# Drupt Mahajan | Portfolio

Personal portfolio website built as part of CSU2215 Introduction to Git and GitHub at Shoolini University.

**Live site:** https://Drupt-hue.github.io

## What's on the site

- **About:** short bio, photo and skills
- **Projects:** three projects with links to their repositories
- **Contact:** email, GitHub and LinkedIn

## Built with

- HTML5
- CSS3 (responsive, supports light and dark mode)
- GitHub Pages for hosting

## Run it locally

```bash
git clone https://github.com/Drupt-hue/Drupt-hue.github.io.git
cd Drupt-hue.github.io
```

Then open `index.html` in your browser. No build step is needed.

## Project structure

```
.
├── index.html   # page content
├── style.css    # styling
├── photo.jpg    # profile photo
└── README.md
```

## Deployment

The site is deployed from the `main` branch (root folder) using GitHub Pages. Every push to `main` updates the live site within a minute or two.
